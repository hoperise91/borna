# Bornă: conventions

Romania's open road database: an NVDB-style portal built from public data. The plan lives in `docs/ROADMAP.md`. Work one roadmap step at a time and commit after each one.

**Where we are (2026-11-19):** Phases 1–3 done; **live at https://bornakm.ro** (Cloudflare Pages from GitHub `hoperise91/borna`, data on R2 at `data.bornakm.ro`). Start a new session by reading `docs/ROADMAP.md` → "Progress" and "Next steps" (next: Phase 4 extras; the weekly refresh runs on GitHub Actions). Deploy: code → `git push` (Pages rebuilds); data → `make tiles deploy-data`. Cloudflare Cache Rule on `data.bornakm.ro` (set 2026-11-19): edge 1 day, browser 1 hour, so new data can take up to a day to show; `borna.refresh` reads the live files with a `?t=` query to skip the cache. The owner prefers a simple, calm, easy UI and checks results against reality (e.g. 130km.ro for motorways): verify geometry, not just totals.

## Non-negotiables
- **Public data only.** Use only sources listed in ROADMAP §2 (or similar public/open ones). No scraping behind logins and no data obtained by formal request until Phase 5.
- **Source, date and licence on every value.** Every row in `road`, `road_segment`, `attribute_event` and `point_object` references `borna.source`. Attribute events and point objects also carry `source_date` and `licence`. Never merge values from two sources into one unlabelled value.
- **CRS:** store geometry in **EPSG:4326**. Compute every length, distance and chainage in **EPSG:3844 (Stereo 70)**. Use constants from `pipeline/borna/config.py` and don't hard-code SRIDs.
- **Linear referencing is the primary key.** Format positions as `DN1 km 27+400`; store them as numeric km (`27.400`, 3 decimals).
- **Bilingual.** All user-facing text is Romanian by default (`/`), with English at `/en/`. Use proper diacritics (ș ț with comma below, not cedilla ş ţ).

## Licensing
- Code is MIT. OSM/Overture-derived layers are ODbL (share-alike), so keep them in separate files from other-licence layers.
- HG 540 register: official act, public under Legea 8/1996 art. 9. Always cite the act and its amendments.
- CESTRIN layers: attribution plus a take-down-on-request policy.

## Layout
- `pipeline/borna/`: Python 3.12 package. One module per Makefile target (`download`, `importer`, `register`, `lrs`, `tiles`).
- `pipeline/sql/`: schema and SQL. `00_schema.sql` runs on first DB start. Schemas: `raw` (untouched imports) and `borna` (the reference network).
- `pipeline/osm2pgsql/roads.lua`: flex style → `raw.osm_roads`, `raw.osm_road_points` (milestones, junctions, level crossings, tolls, borders), `raw.osm_road_routes` (route relations with ordered `way_ids`).
- Downloads write `data/raw/<source>/manifest.json`; `make import` loads them and upserts `borna.source`. Overture lands in `raw.overture_segment` / `raw.overture_connector` (nested fields as jsonb). Its bbox covers neighbouring countries too: clip with GISCO boundaries (Phase 1 step 6).
- `make register` parses the HG 540/2000 annexes (`data/raw/hg540/anexe.html`, newest consolidation from legislatie.just.ro) into `borna.register_entry` (one row per published table row, lists `national`, `county_dn`, `dj`, `dc`, `dp`) and derives `borna.road` (one row per ref; national roads have `county` NULL; county codes are ISO 3166-2:RO). It checks parsed sums against the totals printed in the act and writes `data/out/hg540/{register,totals_check,amendments,problems}.csv`. Known typos in the act go in `REF_CORRECTIONS` with a reason; never silently change official values.
- `gisco` → `raw.gisco_nuts` (NUTS 2024, `county` on level 3) and `raw.gisco_lau` (3,181 UATs; `siruta`, `county`). `ins_trn139a` → `raw.ins_trn139a` (INS road length by category × surface × area × year; `county` set on county rows). County names → ISO codes via `borna.romania.county_code`.
- `aadt_end` → `raw.end_major_roads`: open AADT (CC BY 4.0, data.gov.ro) from the Environmental Noise Directive reporting, only roads above 3M vehicles/year (299 sections, 72 roads); `aadt` = annualTrafficFlow / 365. The full CESTRIN 2022 census layer is access-restricted: Phase 5 request.
- EuroRegionalMap (Open Maps for Europe WFS, token in `.env` as `ERM_TOKEN`): checked 2026-11-18, **Romania is not in the open release** (only neighbouring MD/HU/RS roads), so it can't serve as a DN/DJ cross-check. TENtec (webgate.ec.europa.eu) was down on 2026-11-18; retry before Phase 3.
- Basemaps: satellite = MapTiler satellite-v2 raster, terrain = MapTiler topo-v2 (key `PUBLIC_MAPTILER_KEY` in `web/.env`, git-ignored; allowed origins in MapTiler Cloud: localhost, bornakm.ro, www.bornakm.ro, borna-6h1.pages.dev; MapTiler logo must show while its maps are on). Without a key they fall back to EOX Sentinel-2 (10 m) and OpenTopoMap (slow). ANCPI orthophoto (0.5 m, official) is a candidate when geoportal.ancpi.ro is back online. Overlays go above the basemap's last line/fill layer, below its labels. Esri World Imagery: no, its terms need an ArcGIS account. `borna.pmtiles` is ~24 MB: served from R2 (Pages caps files at 25 MiB), so size isn't capped there, but keep it lean.
- Never work around access controls on a source (403s, token-gated or referer-restricted services). Public-data-only means data that is openly served; anything else waits for a formal request (Phase 5).
- `make lrs` (Phase 2) builds the linear reference network: `borna.osm_way_ref` (normalised OSM road numbers, from ref tags and route relations), `borna.osm_way_county`, one centreline per HG 540 road (ramps dropped, gaps ≤300 m bridged, longest path), km calibrated from county-border km (per-county DN tables), junctions with the roads named at the route's ends, and milestones; output `borna.road_segment` (km_quality calibrated/interpolated/estimated) and `borna.lrs_road`. `borna.locate(ref, km, county)` returns the point. Reports in `data/out/lrs/` (gaps, OSM refs not in the register, checkpoints). Orientation: county-border/junction/milestone controls, else the places named at the route's ends (OSM place nodes), else the roads named there; county roads split into pieces keep the piece nearest those places. `borna.measure(ref, point, county)` is the reverse lookup. `make lrs ARGS=--holdout` keeps every 5th milestone out of calibration and reports the error at them (2026-11-18: median 12 m, 89% within 50 m on DN roads). Private QA points go in `tests/local_checkpoints.csv` (git-ignored; e.g. km-stones read from Google Street View, which must never be published or used as a data source). Checkpoints must stay within 50 m; never move a checkpoint to make it pass unless the point itself was wrong, and say why in its note.
- Network = open roads only: `highway=construction` ways are excluded and exported as the map's dashed `construction` layer (A/DX/DN/V, with `opening_date`). Dual carriageways mapped as two separate pieces: one is dropped before any gap bridging (twins linked at one end form a U, at both ends a loop — both make the longest path run up one side and back). A path that still runs back alongside itself has the doubled leg removed. National roads keep all their pieces (≥500 m), linked through their nearest ends so km runs on across real gaps (A1, A3); the links are gaps, not drawn. When there are no control points and the path disagrees with the official span by >10% (A3: register km 0–68.8), km counts at true scale from the start, as estimated. Sanity check after changes: each A/DX road's mapped km vs its end-to-end distance. National roads open in OSM but missing from HG 540 (motorways A0/A7/A10, expressways DX12, DN numbers like DN12F, and bypasses with informal OSM codes `DNVO…` → `VO…`, e.g. VOF Făgăraș) are added to `borna.road` with `source_id='osm'`, lrs status `osm_only`, km estimated from 0; DN/V take the OSM name as route (motorways don't: OSM names there are construction lots). Only when ≥2 km is mapped as motorway/trunk/primary (named bypasses — Centura/Varianta — ≥1 km, secondary allowed) and it is not mostly on a register road's ways (VO1Z = alias of CORA); the rest go to `data/out/lrs/osm_only.csv` for review. When a new HG 540 consolidation lists one, it switches to official km by itself and the weekly note says so. Cross-checked 2026-11-19 against 130km.ro section lists (A0, A1, A3, A7 match within a few km); 130km.ro is a private site: use it to check, don't import its data.
- HG 540 sometimes lists a road twice after a transfer to the state (DJ113 Covasna = DN11C, annex 2.15 never updated). OSM route relations may still bundle the old county number on the national road. `build_way_refs` takes the national-tagged ways away from a county road when they make up ≥50% of its official length (the duplicate DJ113, or a wandering relation like DJ156 Prahova on DN72); the "now DN11C" note additionally needs a national road of ±25% the same official length (tiles.py; report `data/out/lrs/route_claims_dropped.csv`); the road page says "now DN11C". Ordinary shared stretches (DJ391 along DN38) must stay: removing them breaks county routes apart (tried 2026-11-19: 162 roads got shorter). Open: DJ156 Prahova still picks up 9 km of DN72 via its relation.
- `make attributes` (after `make lrs`) places OSM surface/lanes/maxspeed/width/bridge/tunnel (values as tagged, per way) and open AADT on road km ranges in `borna.attribute_event`, with source, date and licence; same-value ranges merged. OSM `lanes` is per way, so each carriageway of a dual road reports its own lanes.
- `make objects` (after `make lrs`) puts OSM level crossings, motorway junctions, border controls, toll booths (`raw.osm_road_points`) and car-ferry terminals (`raw.osm_ferries`, route=ferry; only vehicle ferries: tagged for motor vehicles or named Bac/ferry; terminal = ferry end within 300 m of a road) into `borna.point_object` (nearest Bornă road within 30 m, most important category wins, km measured; source/date/licence). The spatial query must use the `road_segment` gist index (`&& ST_Expand`): without it, it ran for over an hour. `make attributes` also places E-routes (OSM `network=e-road` relations) as `eroad` events on national roads only. Tiles export an `objects` layer and each road JSON lists `objects` [km, type, name, ref].
- `make qa` (after lrs + attributes) writes `data/out/qa/`: county lengths (HG 540 vs INS vs OSM), county surface shares (INS vs OSM tags; INS modernised + light pavement = paved), exact attribute coverage, gaps by county, OSM refs not in the register, and a README.md summary meant for sharing.
- Weekly refresh (`.github/workflows/weekly-refresh.yml`, Mondays 03:00 UTC, or Actions → Run workflow): downloads fresh osm (not Overture, unused after import); hg540/gisco/ins_trn139a/aadt_end change rarely and some servers refuse CI (legislatie.just.ro closes the connection), so when a download fails it restores the saved copy from the private R2 bucket `borna-raw` (the Mac helper `scripts/weekly-fetch.sh`, installed with `make fetch-install` as LaunchAgent `ro.bornakm.fetch`, runs every 3 h while awake and, unless on a hotspot or Low Data Mode network (`scripts/netcheck.swift`), once every 6 days downloads osm + hg540 and runs `make snapshot-raw`; log `data/out/fetch/fetch.log`; never public: GISCO terms). Geofabrik refuses some CI machines (connection refused), so OSM too falls back to the Mac's saved copy and the note lists it; rebuilds lrs/attributes/qa/tiles, runs `make test`, then `make refresh` (`borna.refresh`) compares with the live `meta/summary.json` and runs the checks (public checkpoints ≤50 m, held-out milestones, road count, A/DX/DN km, no A/DX road shrinking). Pass → `make deploy-data` publishes plus `changes.json` (shown on `/date/`); fail → held back, live data untouched. Each run opens a `weekly-refresh` issue (GitHub emails the owner). Repo secrets: `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`. Change thresholds in `refresh.py`, not by editing checkpoints. `WATCH` in `refresh.py` lists offline public sources (TENtec, ANCPI geoportal); the note says each week whether they are back (information only).
- Schema changes: edit `pipeline/sql/00_schema.sql`, then `make db-reset` (and re-run `make import register`) or apply the matching ALTER by hand.
- `data/`: git-ignored (`raw/` downloads, `interim/`, `out/` exports). Never commit data.
- `web/`: Astro static site. `make tiles` exports `web/public/data/` (git-ignored): `borna.pmtiles`, `roads/<key>.json` (key `DN1` or `CV-DJ121`), `index.json`, `sources.json`, `accuracy.json`, `downloads/`. Pages: map `/` + `/en/` (search, county → road browsing, click/hover a road, km lookup, layer modes; layers panel with background maps — OpenFreeMap light/dark/liberty, OpenTopoMap, EOX Sentinel-2 cloudless 2016 (CC BY 4.0), none — and road-type toggles, both remembered in localStorage; overlays re-added on every style.load; road-number labels as coloured shields (toggle); legend folds (header button; folded by default on phones, remembered); on phones (≤860 px) the sidebar is a bottom sheet over a full-screen map (handle, search focus or opening a list/road slides it up; road fits keep the road above it via `fitPad`); one "Colorează: …" button (menu) picks what colours the map: category/surface/speed/traffic/width/administrator; the map panel's "Date în panou" list (`web/src/lib/datatypes.ts`, grouped Rețea/Drum/Circulație) ticks which data types the road panel shows under "La acest punct" (value at the clicked km, longest covering stretch, with source · date) and in the strip; new data types are rows there, never tabs; hover shows the colouring's value only; the cursor snaps to the nearest road within 12 px (18 px on touch) as a ring, and hover/click use the snapped point; precision details (km quality, distance to the nearest reference point, mapped length, the strip's quality band) and per-value source lines are NOT public — sources sit in tooltips and the panel's "Surse:" line; `?detalii=1` turns the precision details on in that browser (owner only), `?detalii=0` off — width = measured OSM width where tagged, else lanes × 3.5 m (A/DN) or 3.0 m (DJ/DC), labelled as estimate; administrator derived from category per OG 43/1997, DP owner from HG 540. Back from a road → the list it came from or its county list; empty map click deselects), road pages prerendered at `/drum/<KEY>/` (every road) and `/en/road/<KEY>/` (A/DX/DN/V/DJ only: Cloudflare Pages allows 20k files per deploy; now ~10.7k) from `index.json` (`src/lib/site-data.ts`: local `public/data/index.json`, else fetched from R2 at build time; if neither, road pages are skipped with a warning). The HTML carries title, description, H1, route, hreflang and a list of linked neighbouring roads; the script then fills in the rest from `roads/<key>.json`. `/drum/?r=KEY` still works (noindex) and redirects to the static page; link with `roadHref()` in `roads.ts`. `/date/`, `/despre/`. Contact: `CONTACT_EMAIL` in `i18n.ts` (contact@bornakm.ro, Cloudflare Email Routing → owner's Gmail), on `/despre/` and as a "report a mistake" mailto on road pages. SEO: `src/lib/seo.ts` (titles, descriptions, JSON-LD: WebSite+SearchAction on the map, Dataset on `/date/`, BreadcrumbList on roads), `src/pages/sitemap.xml.ts`, `public/robots.txt`; Base.astro takes `description`, `alternates`, `noindex`, `jsonLd`. Data URL: `PUBLIC_DATA_URL` (default `/data`). UI strings in `web/src/lib/i18n.ts` (RO + EN, keep both in sync). Design: simple, calm, route-shield colours (A green, DN red, DJ blue, DC ochre); user wants simple and easy over clever.
- `tests/lrs_checkpoints.csv`: the km-lookup quality gate (road, km, lat, lon, note). Target ±50 m. Note where each km value comes from (local knowledge, HG 540, milestone photo); approximate ones say so.
